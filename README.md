# NotTyped — Website

The static marketing and legal site for [NotTyped](https://nottyped.com), a
handwriting-only social media app.

## Contents

| File | Purpose |
| --- | --- |
| `index.html` | Landing page (hero, screens marquee, share-as-video spotlight, how it works, features, App Store badge) |
| `privacy.html` | Privacy Policy |
| `terms.html` | Terms of Service |
| `guidelines.html` | Community Guidelines |
| `support.html` | Support / Help (FAQ + contact) |
| `styles.css` | Shared stylesheet (palette, header, footer, type) |
| `assets/` | Brand images — `wordmark.png` (header/hero logo), `appicon.svg` + `appicon-180/1024.png` (hero icon, favicon) |
| `assets/screens/` | The six App Store panels as 706px WebP (`panel-1..6.webp`), shown in the landing page marquee |
| `assets/og.jpg` | 1200x630 link-preview image for X, iMessage, Slack and friends |
| `CNAME` | Custom domain for GitHub Pages (`nottyped.com`) |

Pure HTML + CSS — no JavaScript, no build step, no frameworks. All links between
pages use **relative paths** (e.g. `href="privacy.html"`), so the site works both
at `username.github.io/<repo>/` during testing and at `nottyped.com` in production.

The wordmark and app icon are the official brand assets (`assets/`). Headings use
**Playfair Display** and body text uses **Hanken Grotesk**, loaded from Google Fonts
via `<link>` in each page's `<head>` — the only external dependency. If you'd rather
not depend on Google Fonts (e.g. for privacy), the fonts are SIL OFL licensed and can
be self-hosted; the page still renders with serif/sans fallbacks if the fonts fail to load.

## Updating the screenshots

The landing page reuses the App Store marketing panels, which live outside this
repo in `~/NotTyped-screenshots/marketing/` (sources in `src/p1..p6.html`). To
refresh them after a new store upload:

- Panels: `cwebp -q 78 -resize 706 0 panel-iphone-N.png -o assets/screens/panel-N.webp`
- Link preview: `og.html` in the same folder renders with headless Chrome
  (`--headless=new --window-size=1200,630 --screenshot`), then `sips -s format jpeg`
  to `assets/og.jpg`.
- The hero's two handwritten lines are Hershey script strokes inlined in `index.html`:
  "Don't type it." is the SVG from `src/p1.html`; "Write it." was generated by
  `hero-strokes.py` in the same folder (`pip install Hershey-Fonts`), which renders
  any phrase in the captions' geometry with the `pathLength="1"` and per-stroke
  `--d`/`--t` timings that `styles.css` animates.
- The looping share card in the "Watch it being written" section is generated by
  `playback-card.py` in the same folder (it reuses `hero-strokes.py`). Run it and
  paste the output over the `<div class="sharecard">` in `index.html`; the note's
  lines and the handwriting size are its first two arguments (leave out the size
  and it grows the note the way the app's share page does, up to 2x). The card
  copies the app's page: letterhead at the top, note centered, @handle under the
  end of the ink, then the closing card the video ends on. It shares numbers with
  the Motion block in `styles.css` (the 400 dash and the 77% / 81% / 97% fades),
  so change them in both places or not at all. It is a demo in the Hershey hand,
  like the hero, and not a real export from the app.
- Next to it, the note card with the play button (1.2.0's "Watch it written") is
  generated by `note-card.py` in the same folder. It draws the same note as the
  share card at feed size on a copy of the app's note-page card, measured from the
  store screenshot `iphone-3-detail.png`; paste its output over the
  `<div class="notecard">`. It shares the 400 dash and its own 14% / 86% (play
  tapped, playback over) with the Motion block in `styles.css`. Its icons are
  simple outlines drawn for the site, not SF Symbols.

## Deployment (GitHub Pages)

1. **Create a new GitHub repo** (e.g. `nottyped-site`).
2. **Push the contents of this `website/` folder to the `main` branch.** The HTML
   files must be at the repo root so GitHub Pages serves `index.html` as the home
   page.
3. In the repo, go to **Settings → Pages → Source: `main` branch** → **Save**.
4. **Custom domain:** in the same Pages settings, enter `nottyped.com` in the
   **Custom domain** field and save. (The included `CNAME` file sets this too.)
5. **DNS — A records:** in your DNS provider (Cloudflare), add four `A` records for
   the apex domain `nottyped.com` pointing to GitHub Pages:
   - `185.199.108.153`
   - `185.199.109.153`
   - `185.199.110.153`
   - `185.199.111.153`
6. **DNS — CNAME record:** add a `CNAME` record for `www` pointing to
   `yourusername.github.io`.
7. Wait for DNS to propagate and for GitHub to provision the TLS certificate
   (enable **Enforce HTTPS** in Pages once it's available). The site will be live at
   **https://nottyped.com**.

> Note: if you serve the site from a project path like
> `username.github.io/nottyped-site/` for testing, the relative links still work —
> no changes needed.
